    What Lighthouse adds to Beacon

    Open Lighthouse's own pages from the Lighthouse menu in Beacon. Features it adds to Beacon's pages are marked with the Lighthouse logo.

    Lighthouse Aided Dispatch

    LAD is a tasking dashboard. Track and task teams and incidents on one screen, with a live map, ICEMS messages, radio and vehicle tracking, alerts and shared map layers.

    LAD user guide →

    Situational awareness map

    Extra layers on Beacon's map: traffic cameras and incidents, fires, power outages, aircraft, SES headquarters and vehicle locations.

    Jobs and teams

    • Nearest vehicles with driving routes and times
    • Instant Task: task, sector and categorise in two clicks
    • Other jobs at the same address
    • myAvailability responses and recent activations

    Dashboards

    Live Job Summary, Job Statistics and Team Summary screens, made for the big screen in an operations room.

    Registers and exports

    • Quick filters such as "All outstanding jobs"
    • Saved filter and message recipient collections
    • Job and NITC exports to CSV

    LAD at a glance

    A few of the things you can do in Lighthouse Aided Dispatch. Screenshots use made-up demo data.

    Read the LAD guide →

    Install Lighthouse

    You need a NSW SES Beacon account and Google Chrome on a Windows, Mac or Linux computer. Mobile browsers don't support extensions.

    Already on an NSW SES computer? Lighthouse is installed for you.

    Latest Version

    Tested and stable. Use this for operations.

    Latest Development Version

    Gets new features and fixes first, but may have bugs. Not recommended for operations.

    Help and support

    Found a problem? Tell us on the Facebook group or raise a GitHub issue. Support is provided by volunteers, so we'll help as soon as SES duties (and life) allow.

    The NSW SES Helpdesk can't help with Lighthouse. If Lighthouse is stopping you from using Beacon, remove the extension.

    How it works

    Lighthouse runs in your browser and works with the same information and actions as Beacon, so your Beacon permissions, security checks and audit logging all still apply.

    A few shared features, such as collaborative map layers, also use Lighthouse's own servers. You need to be signed in to Beacon to use them.

    Help build Lighthouse

    We welcome help with code (JavaScript, HTML and CSS), design, documentation and testing. All of Lighthouse is open source. The GitHub repository explains how to build and run it.

    Pull requests are welcome, including fixes to this site: the user guides and What's New live in the repository's docs/ folder.
